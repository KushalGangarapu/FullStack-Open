# Full Stack Open - Part 1: Introduction to React

This directory contains the solutions for Part 1 of the Full Stack Open course (Exercises 1.1 - 1.14).

## Exercises Summary

### Course Information (1.1 - 1.5)
Located in [`courseinfo`](courseinfo)
- **1.1: Course Information, step 1** - Refactored app into Header, Content, and Total components.
- **1.2: Course Information, step 2** - Refactored Content component to render three Part components.
- **1.3: Course Information, step 3** - Transitioned variables to JavaScript objects.
- **1.4: Course Information, step 4** - Placed objects into an array passed as props to components.
- **1.5: Course Information, step 5** - Combined course name and parts array into a single JavaScript object.

### Unicafe (1.6 - 1.11)
Located in [`unicafe`](unicafe)
- **1.6: Unicafe, step 1** - Feedback collection application with good, neutral, and bad state counters.
- **1.7: Unicafe, step 2** - Added total feedback, average score, and percentage of positive feedback.
- **1.8: Unicafe, step 3** - Extracted statistics rendering into a separate Statistics component.
- **1.9: Unicafe, step 4** - Displayed statistics conditionally only after feedback is given.
- **1.10: Unicafe, step 5** - Extracted Button and StatisticLine components.
- **1.11*: Unicafe, step 6** - Rendered statistics inside an HTML table layout.

### Anecdotes (1.12 - 1.14)
Located in [`anecdotes`](anecdotes)
- **1.12*: Anecdotes, step 1** - Random anecdote selection on button click.
- **1.13*: Anecdotes, step 2** - Voting functionality stored in component state array.
- **1.14*: Anecdotes, step 3** - Displayed the anecdote with the highest number of votes.
